\section{Uplift model monitoring: embedded FSDS + LOCO--AUUC}

\paragraph{What this is.}
A \textbf{straightforward use case}: monitor an uplift model with the \textbf{same batch FSDS pipeline} as elsewhere.
REF = calibration batch; LIVE = current deployment batch.
The only special piece is the ranking metric---\textbf{AUUC instead of MSE}---plus LOCO that \textbf{retrains} the meta-learner on REF after each feature-group drop.

\paragraph{Three steps.}
\begin{enumerate}\itemsep4pt
  \item \textbf{FSDS on $X$.} MMD$^2$, domain RF AUC$(X)$, SRM on $T$, optional ESS overlap before LOCO.
  \item \textbf{LOCO--AUUC.} Meta-learner on REF $\rightarrow$ AUUC on REF holdout and LIVE; LOCO drops localize feature groups.
  \item \textbf{PO-risk (optional).} Same REF/LIVE stack; tests $Y\mid X$ / concept drift when AUUC falls but $X$ is flat.
\end{enumerate}

\paragraph{Why AUUC matters.}
$\mathrm{AUUC}_{\mathrm{live}}$ drops when \textbf{covariate shift} hurts ranking on LIVE (often with MMD/domain AUC up, ESS still OK)
and when \textbf{concept drift} changes the treatment effect surface (often with flat MMD, PO-risk significant, LOCO Spearman flipping).
FSDS on $X$ and PO-risk tell you \emph{which} case you face; AUUC tells you ranking broke; LOCO tells you \emph{where} to act.

\paragraph{Notation (compact).}
$W\in\{0,1\}$ batch (REF/LIVE); $T\in\{0,1\}$ uplift treatment; $\Delta_{\mathrm{AUUC}}=\mathrm{AUUC}_{\mathrm{ref}}-\mathrm{AUUC}_{\mathrm{live}}$;
$\mathrm{drop}_{\mathrm{live}}^{(g)}=\mathrm{AUUC}_{\mathrm{live}}^{\mathrm{full}}-\mathrm{AUUC}_{\mathrm{live}}^{(-g)}$ after dropping group $g$ and retraining on REF.
